# db-migrations

SQL migrations for the openRun database, generated by drizzle-kit from the schema in `libs/db`.

Migrations are kept in their own Nx project so that `nx affected` only runs migration targets when the schema or the migrations change.

| Target                          | What it does                                                     |
| ------------------------------- | ---------------------------------------------------------------- |
| `nx run db-migrations:generate` | Generates a new migration from changes to `libs/db/src/schema`   |
| `nx run db-migrations:check`    | Fails if the schema has changed without a migration (runs in CI) |
| `nx run db-migrations:migrate`  | Applies pending migrations to `DATABASE_URL`                     |
| `nx run db-migrations:test`     | Applies every migration to an in-memory database                 |

Never edit a migration that has been released. Self-hosted instances apply migrations automatically when the API starts.
